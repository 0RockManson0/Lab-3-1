Задание 1. Заполнение двумерных массивов
Текст задачи
Первый массив, размерностью n x m, заполняется данными, вводимыми с клавиатуры, так что заполнение ведется по диагоналям параллельным главной, начиная с левого нижнего угла.
Второй массив, размерностью n x n, заполняется случайными числами так, что в каждой строке получается убывающая последовательность элементов.
Третий массив, размерностью n x n, заполняется для произвольного n так же, как для n=5:

 1 16 15 14 13
 2 17 24 23 12
 3 18 25 22 11
 4 19 20 21 10
 5  6  7  8  9

Алгоритм решения

    Создать класс MatrixClass с единственным полем _data типа int[,] (двумерный массив) и полями _rows, _cols для хранения размерности.
    Реализовать конструктор MatrixClass(int n, int m) для первого массива: заполнить матрицу по диагоналям, параллельным главной, начиная с левого нижнего угла. Использовать переменную diff = i - j, меняя её от n-1 до -(m-1). Для каждой диагонали вычислить диапазон строк через Math.Max и Math.Min и запросить у пользователя ввод каждого элемента через ConsoleHelper.ReadInt().
    Реализовать конструктор MatrixClass(int n) для второго массива: для каждой строки сгенерировать n случайных чисел через Random.Next(-100, 100), отсортировать их по убыванию методом пузырьковой сортировки (без LINQ) и записать в матрицу.
    Реализовать конструктор MatrixClass(int n, string mode) для третьего массива: заполнить матрицу числами от 1 до n² по спирали по часовой стрелке. Использовать четыре переменные-границы (top, bottom, left, right), которые сужаются после каждого прохода.
    Переопределить метод ToString() для вывода матрицы в виде таблицы с использованием PadLeft(6) для выравнивания столбцов.
    В методе RunTask1() запросить у пользователя размерности n и m, создать три объекта MatrixClass через разные конструкторы и вывести их на экран.

Задание 2. Работа с двумерными массивами
Текст задачи
В двумерном массиве содержатся результаты двух голосований n депутатов. При голосовании требовалось ответить "Да" или "Нет". Подсчитайте каких депутатов больше: тех, кто оба раза проголосовал одинаково, или тех кто изменил свое решение.
Алгоритм решения

    В классе MatrixClass реализовать метод AnalyzeVoting(), который работает с уже существующим полем _data размерностью n×2.
    Инициализировать два счётчика: sameCount = 0 (депутаты, проголосовавшие одинаково) и changedCount = 0 (депутаты, изменившие решение).
    В цикле for пройти по всем строкам массива (каждая строка — один депутат).
    Для каждой строки получить значения из столбцов: v1 = _data[i, 0] (первое голосование) и v2 = _data[i, 1] (второе голосование). Использовать числа 1 ("Да") и 0 ("Нет").
    С помощью тернарного оператора преобразовать числа в строки "Да"/"Нет" для вывода.
    Сравнить v1 и v2: если равны — увеличить sameCount, иначе — changedCount.
    Вывести информацию о каждом депутате и итоговые счётчики.
    Сравнить счётчики и вывести, кого больше: проголосовавших одинаково, изменивших решение, или количество равно.
    В методе RunTask2() запросить количество депутатов n, создать матрицу n×2 через конструктор с ручным вводом (manual = true) и вызвать метод AnalyzeVoting().

Задание 3. Работа с двумерными массивами как с матрицами
Текст задачи
Вычислить значение матричного выражения: A^T + B − 3·C
Перегрузить необходимые операторы и посчитать значение матричного выражения (решение без перегрузки не принимается). Перегрузить метод ToString() — сформировать строку из двумерного массива для отображения его на экране в виде таблицы. Приложить в отчёт скрин-шот проверки на онлайн-калькуляторе, чтобы показать, что выражение посчитано верно.
Алгоритм решения

    В классе MatrixClass перегрузить унарный оператор ~ для транспонирования матрицы: создать новую матрицу с swapped размерностями (_cols × _rows) и в цикле поменять индексы местами: result._data[j, i] = m._data[i, j].
    Перегрузить бинарный оператор + для сложения матриц: создать новую матрицу того же размера и в цикле сложить соответствующие элементы: result._data[i, j] = a._data[i, j] + b._data[i, j].
    Перегрузить бинарный оператор - для вычитания матриц по аналогии со сложением.
    Перегрузить бинарный оператор * для умножения матрицы на скаляр (в обоих направлениях: matrix * scalar и scalar * matrix): создать новую матрицу и умножить каждый элемент на скаляр.
    Все операторы создают новые объекты MatrixClass через конструктор с manual = false, чтобы не запрашивать ввод при промежуточных вычислениях.
    Переопределить метод ToString() для вывода матрицы в виде таблицы.
    В методе RunTask3() запросить размер матриц n, создать три матрицы A, B, C через ручной ввод и вычислить выражение ~A + B - 3 * C в одну строку, используя перегруженные операторы.
    Вывести результат и приложить скриншот проверки на онлайн-калькуляторе (например, matrixcalc.org).

    В классе FileTasks реализовать отдельный метод FillBinaryRandom(string path, int count) для заполнения исходного бинарного файла случайными числами через BinaryWriter и Random.Next(-10, 10) (диапазон с повторами).

Задание 6. Текстовые файлы
Текст задачи
В текстовом файле хранятся целые числа по одному в строке. Найти сумму элементов, оканчивающихся на заданную цифру.
Алгоритм решения

    Реализовать отдельные методы FillText6Random и FillText6Manual для заполнения файла случайными числами или вручную (по одному числу в строке через StreamWriter.WriteLine()).
    В методе Task6() предложить выбор режима, заполнить файл и вывести его содержимое через ReadTextFile().
    Запросить у пользователя цифру от 0 до 9 через ConsoleHelper.ReadInt().
    Считать файл построчно через StreamReader.ReadLine() в цикле while.
    Для каждой строки преобразовать её в число через int.TryParse().

    Вывести итоговую сумму.
